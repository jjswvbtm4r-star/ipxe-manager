# 部署与验证记录

## v1.2.0 发布状态

- 管理器、安装入口、只读验收工具和打包工具已迁移到 Python 3.10+ 标准库。
- 三个 ZIP 包已重新生成；Python 主程序、安装程序和验收程序在 ZIP 内标记为可执行。
- 本次发布覆盖源代码、说明文档和安装包，不包含现场服务器部署。
- 目标服务器 `10.10.12.180` 仍运行 v1.1.0；用户此前确认其 PXE 菜单可启动。
- Python 版尚未在 Linux 服务器执行；dnsmasq/nginx 配置、服务回滚、DHCP/TFTP/HTTP 及 Legacy/UEFI 客户端启动都尚未由本版本实测。

## v1.1.0 已有环境记录

v1.1.0 曾检查服务状态、双网口菜单 URL、OS 安装树文件和引导文件传输；现场 PXE 启动成功的记录仅适用于当时部署的 Bash 版本。

后续部署 v1.2.0 前，应先在隔离装机网络执行部署和只读验收，再逐项实测 Legacy IPv4、UEFI IPv4、UEFI IPv6，以及至少一个 OS 安装器启动流程。不能把旧版的 PXE 成功记录当作新版的运行验证。
